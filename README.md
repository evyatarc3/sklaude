# ◎ רדאר סקילים

אינדקס סקילים ל-Claude שמתעדכן אוטומטית כל יום. האתר מציג סקילים חמים, מסנן לפי נושאים ומאפשר חיפוש חופשי (גם בעברית).
**אין שרת ואין API בתשלום.** הכל רץ על GitHub Actions ו-GitHub Pages, שהם חינמיים בריפו ציבורי.

## איך זה עובד

```
GitHub Actions (כל יום ב-03:17 UTC)
  scripts/collect.mjs
   ├─ חיפוש ריפואים בגיטהאב לפי topics ומילות מפתח
   ├─ חיפוש קוד: קבצי SKILL.md
   ├─ רשימות awesome-* (מחלץ מהן קישורים)
   ├─ Hacker News: דיונים על סקילים (לשונית "מדברים על זה")
   └─ הגשות ידניות: data/submissions.json, כולל סקילים מחוץ לגיטהאב
        ↓  לכל ריפו: איתור כל קבצי SKILL.md וקריאת ה-frontmatter
        ↓  תיוג לפי נושאים (config/categories.json) + סימני סיכון סטטיים
        ↓  שמירת היסטוריית כוכבים ← חישוב "+כוכבים השבוע"
  site/data/index.json        ←  אינדקס קומפקטי: האתר טוען אותו ומחפש בדפדפן
  site/data/repos/<repo>.json ←  פרטים מלאים לכל ריפו, נטען רק בעמוד של סקיל
  site/data/hot.json          ←  רשימות קריאות (חמים, פופולריים, חדשים) לכלים חיצוניים
```

| קובץ | תפקיד |
|---|---|
| `scripts/collect.mjs` | האוסף. רץ על Node 20 ומעלה, בלי תלויות |
| `config/sources.json` | מאיפה לאסוף: שאילתות, רשימות awesome, ריפואים קבועים, מגבלות |
| `config/categories.json` | נושאים ומילות מפתח, בעברית ובאנגלית |
| `data/submissions.json` | סקילים שנוספו ידנית, דרך טופס ה-Issue |
| `data/state.json` | מטמון: ריפו שלא השתנה לא נסרק שוב |
| `data/stars-history.json` | כוכבים לפי יום, משמש לחישוב "חמים" |
| `site/` | האתר: HTML, CSS ו-JS בלי ספריות חיצוניות |

## הפעלה (פעם אחת)

1. **ריפו ציבורי:** Settings → General → Danger Zone → Change visibility → Public.
2. **Pages:** Settings → Pages → Source: **GitHub Actions**.
3. **הרצה ראשונה:** Actions → *Update skills & deploy site* → **Run workflow**.
   הכתובת תהיה `https://<user>.github.io/sklaude/`.

מכאן הכל אוטומטי. כל יום נאספים נתונים חדשים, נשמרים כ-commit, והאתר מתפרס מחדש.

> בהרצה הראשונה ייתכן שלא כל הריפואים ייסרקו, כי ה-API של Actions מוגבל לכ-1000 בקשות בשעה. מה שלא נסרק נדחה להרצה הבאה, ואחרי יום-יומיים האינדקס מלא. "חמים" מבוסס בהתחלה על הערכה (מסומנת ב-\*). אחרי שבוע של היסטוריה החישוב מדויק.

## סקילים שלא בגיטהאב

באתר יש כפתור **"+ הוספת סקיל"** שפותח טופס Issue. אפשר להגיש בו:
- קישור לתיקייה בגיטהאב,
- קישור ישיר לקובץ `SKILL.md` שמתארח בכל מקום,
- או עמוד של סקיל באתר אחר, עם שם ותיאור.

כשמוסיפים להגשה את התווית `approved`, Action מוסיף אותה ל-`data/submissions.json` ומעדכן את האתר.
ההגשות לא נכנסות בלי אישור, כדי למנוע ספאם. הטקסט של ה-Issue נקרא ב-JS בלבד ולא מוכנס לפקודות shell.

## בטיחות

סקיל יכול להריץ קוד, ולכן כל כרטיס באתר מציג **סימני סיכון** מבדיקה סטטית:
סקריפטים בתיקייה, גישה לרשת, אזכור מפתחות או סיסמאות, פקודות הרסניות, קוד מקודד או eval, התקנה אוטומטית, וקבצים בינאריים.
זה סינון ראשוני בלבד, לא אישור שהסקיל בטוח.

## שינויים נפוצים

- **להוסיף מקור:** להוסיף שאילתה או רשימת awesome ב-`config/sources.json`.
- **להוסיף נושא:** להוסיף קטגוריה עם `keywords` (אנגלית) ו-`he` (מילים לחיפוש בעברית) ב-`config/categories.json`.
- **הרצה מקומית:**
  ```bash
  GITHUB_TOKEN=<token> npm run collect     # הרצה מלאה
  QUICK=1 WRITE=1 npm run collect          # הרצה קטנה לבדיקה
  npm run serve                            # http://localhost:8000
  ```

## עמוד לכל סקיל

לחיצה על שם של סקיל פותחת עמוד משלו, עם כתובת שאפשר לשתף (`#s=owner/repo/path`). בעמוד מוצגים:
- ה-SKILL.md עצמו, שנטען בזמן אמת מגיטהאב. ה-frontmatter מוצג כמו בקובץ, וכל HTML שבקובץ מוצג כטקסט ולא מורץ.
- פקודת התקנה ל-Claude Code.
- הסבר על כל סימן סיכון.
- רשימת הקבצים בתיקייה.
- סקילים נוספים מאותו ריפו.

## תיאורים בעברית

התיאורים מתורגמים לעברית בתוך ההרצה היומית, בלי API ובלי עלות. המודלים הם מודלי תרגום פתוחים של Helsinki-NLP, שרצים על המעבד של Actions:
- `opus-mt-en-he`: מאנגלית לעברית.
- `opus-mt-mul-en`: משפות אחרות (סינית, רוסית, קוריאנית ועוד) לאנגלית, ומשם לעברית.
- תיאורים שכבר כתובים בעברית נשארים כמו שהם.

התרגום נעשה משפט אחרי משפט, וכל משפט נשמר במטמון (`data/he-cache.json`). כל הרצה מתרגמת רק טקסט חדש או טקסט שהשתנה. הסקילים עם הכי הרבה כוכבים מתורגמים ראשונים, וכל הרצה מוגבלת ל-45 דקות. מה שלא הספיק להיתרגם ממשיך בהרצה הבאה.

- `site/data/he.json`: תיאור קצר בעברית לכל סקיל, באותו סדר כמו `index.json`. נטען ברקע אחרי שהרשימה מוצגת.
- `site/data/repos/*.json`: השדה `he` מכיל את התרגום המלא, שמוצג בעמוד הסקיל.

באתר אפשר לכבות את העברית ולחזור לתיאורים המקוריים. הטקסט המקורי מוצג גם כשמעבירים את העכבר על תיאור.
כדי להריץ רק תרגום, בלי איסוף ובלי לבזבז את מכסת ה-API: Actions → Update skills & deploy site → Run workflow, ולהוריד את הסימון מ-collect.

## פורמט הנתונים (index.json, גרסה 2)

כדי שהקובץ יהיה קטן, כל ריפו נשמר פעם אחת וכל סקיל מצביע עליו:

```
repos:  [full_name, stars, delta7, branch, updated, license, official(0/1), trendEstimated(0/1)]
skills: [repoIdx, path, name ("" = כמו שם התיקייה), description (עד 200 תווים), [categoryIdx…], flagBits, risk(l/m/h/u), added, copies?]
flags:  סדר הביטים של flagBits
```

התיאור המלא ורשימת הקבצים נמצאים ב-`data/repos/<owner>__<repo>.json`.

## הסקיל github-skill-scout

בתיקייה `integrations/github-skill-scout/` יש גרסה של הסקיל שמחפשת קודם באינדקס של האתר, במקום לחפש בגיטהאב בכל פעם:

```bash
python3 scripts/radar.py search "pdf form fill"   # חיפוש (מילים באנגלית)
python3 scripts/radar.py hot                      # הכי חמים השבוע
python3 scripts/radar.py show owner/repo/path     # פרטים מלאים ורשימת קבצים
```

הסקריפט משתמש רק בספרייה הסטנדרטית של Python. שלבי הבדיקה וההתקנה של הסקיל לא השתנו.
להתקנה: לדחוס את התיקייה ל-zip ולהעלות אותה בהגדרות של claude.ai, באזור Skills, במקום הגרסה הקודמת.
